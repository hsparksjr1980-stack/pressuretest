# Product Roadmap

## Weekly Operating Limit

Each week may include no more than one approved product task. Supporting fixes necessary to complete that task are allowed.

## Product Task Eligibility

A product task may begin only when a GitHub issue has:

- `product` label.
- `ready` label.
- Acceptance criteria.
- Defined out-of-scope items.
- Risk level.
- Current weekly cycle.
