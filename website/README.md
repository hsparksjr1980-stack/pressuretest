# PressureTest Website

This is the Next.js marketing site for PressureTest.

The product direction is currently focused on **PressureTest: Franchise**:

**Stress-test a franchise before you sign, borrow, lease, or invest.**

Startup and Acquisition are future placeholders only and should not be marketed as active workflows in this phase.

## Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Messaging Guardrails

- Quick Assessment is the default path.
- Full Review is a depth toggle within the same workflow, not a separate product.
- The report is the core artifact.
- Paid review remains manual.
- Do not imply Stripe, native apps, Startup, Acquisition, AI agents, or Pro tools are part of the active Franchise Beta.
- Do not present PressureTest as legal, tax, accounting, lending, or investment advice.
